Prepare your lecture library

Import captions once on your laptop, build the index, then serve it to everyone. The web server only reads the prepared index.

python -m app.cli ingest --limit 3
python -m app.cli index
python -m app.cli serve

Start with three lectures to check caption quality. Remove --limit 3 to fetch the full playlist. Failed videos are listed in data/ingest_report.json; rerunning resumes cached work.

The included demo uses original DSA notes. It has no Striver transcripts or lecture timestamps until you index real videos.
