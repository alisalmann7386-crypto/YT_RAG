All catalog lectures can be found by title. Verified timestamps and extractive summaries require indexed captions.

Prepare your lecture library

Prepare captions once, then serve the index to everyone. Your visitors search the prepared library.

python -m app.cli ingest --workers 1
python -m app.cli index
python -m app.cli serve

Rerunning resumes cached work. Missing or blocked videos are listed in data/ingest_report.json. You can also import timestamped JSON, SRT, or VTT captions.

The fresh-install demo uses original DSA notes. Add the prepared lecture index to enable real caption timestamps.
